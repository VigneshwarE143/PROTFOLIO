# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio built using **React, Vite, and Tailwind CSS**. This website showcases my skills, projects, education, and contact information with a professional UI, dark/light mode, and a functional contact form powered by EmailJS.

🔗 **Live Demo:**  
https://protfolio-git-main-vigneshwars-projects-ea6ead1c.vercel.app/

---

# 🚀 Features

- Modern and clean single-page design
- Light / Dark mode toggle
- Fully responsive (Mobile, Tablet, Desktop)
- Project showcase with featured project cards
- Skills and education sections
- Functional contact form using EmailJS
- Fast performance with Vite
- Clean and reusable component structure

# ⚙️ Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```

## 2. Install dependencies

```bash
npm install
```

## 3. Run locally

```bash
npm run dev
```

Open in browser:  
http://localhost:5173/

---

## 4. Build for production

```bash
npm run build
```

---

## 5. Preview production build

```bash
npm run preview
```

# 📧 EmailJS Configuration

This project uses EmailJS for handling the contact form.

To enable it:

1. Create an account at https://www.emailjs.com/
2. Create a service
3. Create an email template
4. Get your Public Key
5. Update the keys in your project:

```
src/services/emailService.js
```
